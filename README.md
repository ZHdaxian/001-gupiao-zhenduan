【001-股票360°全景诊断系统】

🔖 标签：#金融 #股票 #A股 #港股 #美股 #投资分析 #量化

📌 一句话介绍：
拥有200年经验的全球宏观对冲基金首席策略师，精通A股、港股、美股，从宏观到微观一键生成专业诊断报告，覆盖基本面(40%)+技术面(30%)+资金面(20%)+消息面(10%)四大维度。

✅ 核心功能：
• 🌏 覆盖市场：A股（沪深）、港股（沪深港通）、美股（中概/ADR）
• 📊 分析维度：基本面(40%) + 技术面(30%) + 资金面(20%) + 消息面(10%)
• 🎯 输出内容：综合评级、关键价格位（止损/建仓/补仓/减仓）、多维评分、研报汇总、风险提示、操作策略
• ⚡ 触发方式：股票代码 / 股票名称

💬 使用示例：
• "分析 000001.SZ"
• "帮我诊断贵州茅台"
• "腾讯控股(00700.HK)股票诊断"
• "AAPL 美股诊断"

📖 详细说明：
输入任意股票代码或名称，自动调用 NeoData 金融数据 API，实时获取：
• 实时行情、涨跌幅、市值
• 近3-5年财务数据（ROE、毛利率、资产负债率、营收增速）
• 技术面数据（均线、MACD、RSI、布林带、支撑压力位）
• 资金流向（主力、北向、融资融券、股东户数）
• 最新研报、机构评级、目标价

输出结构化诊断报告，包含：
• 综合评分（0-100分）+ 星级评级
• 具体买卖点位（止损/建仓/补仓/减仓）
• 风险提示（行业、公司、系统性）
• 操作策略（仓位建议、持有周期）

📎 适用人群：
• 散户投资者：需要个股诊断参考
• 机构分析师：快速生成研判框架
• 基金从业者：辅助投资决策

⚠️ 免责声明：本技能输出内容仅供参考，不构成任何投资建议。股市有风险，投资需谨慎。
